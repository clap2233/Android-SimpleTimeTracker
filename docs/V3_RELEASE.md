# V3 真机测试候选版

版本：`1.59-life-clock-v3`（160），Android 5 及以上。使用既有正式包名与发布签名，面向已有 UI2 用户覆盖安装测试；这不是全部验收完成声明。

## 安装

1. 在旧版的“设置 → 数据与备份 → 完整备份与恢复”导出一份包含照片的 ZIP，保存到手机之外。
2. 直接安装 `life-time-clock-v3.apk`，选择更新，不卸载旧版。正式包名为 `app.lifetimeclock.android`。
3. 若原应用名称带“开发版”，两个包不能覆盖，需通过完整 ZIP 手动迁入正式版。

数据库从 37 升级到 38。不要通过卸载重装来解决覆盖问题；旧版无法直接读取新版数据库，保留升级前备份用于回退。

## 这版可以测试什么

- 真实时长不再要求 15 分钟倍数；12 分 40 秒等记录可保存并确认。
- 在活动设置中选择自由记录、专注退出轻提醒或周期收尾提醒，模板可覆盖。专注 8／22 分钟退出时可以立即结束；节点分钟内不提示，过程中不主动响铃。
- 经历详情中意义可填 −5 至＋5，快乐保持 1 至 5；两项均填写才显示合计。意义 0 与未填写不同。恢复感可选、可清除。
- 新增规划入口：待办、日／周安排、重复、缓冲和计划与实际关联。安排计划不会自动增加实际经历。
- 完整备份支持新字段；服务器已兼容新版。成功手动备份后可由 Codex 只读分析，应用内不含聊天模型。

## 当前验证与限制

已通过 172 项领域、31 项数据、17 项云端检查，以及 Android 5 的 11 项、Android 15 的 15 项定向界面回归。以上自动化与开发包结果不能替代用户真机反馈。

仍待完整验收：真机后台提醒与通知权限、真实手机云备份和分析、跨设备恢复、全部小屏／大字号／深色状态。规划冲突预览目前只检查起点后 90 天；编辑弹窗遇到系统重建时草稿保留仍待补齐。

建议优先反馈：能否覆盖安装并保留旧数据、专注退出提示是否符合预期、负意义／恢复感是否保存、规划是否容易操作。详细证据见 [验证台账](V3_STATUS.md)。
