# V3.1 图表与规划修订

版本 `1.59-life-clock-v3.1`（162），数据库 38，快照格式 2。沿用既有正式签名，可直接更新 UI2／V3；先导出完整 ZIP，再安装，保留升级前备份。

## 本次更新

- 周图改为轻网格、圆角色块、星期与日期双层标题、选中日标记。完整 00:00—24:00 总览缩短到 360dp，类别原色与真实时间保持不变；短经历仍可通过本周经历列表打开。
- 类别分布改为彩色圆点、时长、占比与圆角比例条，待整理和进行中有数据时再补充，减少重复零值。
- 快乐／意义改为紧凑条形分布，意义保留 −5 至＋5 全部 11 档，负分、中性、正分分别着色；未评分单列，条长按该图最大条数缩放，两张评分图不共用比例尺。
- 详细统计的环图加大、环宽减小，移除粒子装饰，保留原有点击与类别颜色。
- 新增／编辑待办和安排时段，在页面重建后恢复标题、备注、日期、时间、时长、重要／紧急、模板、重复规则及提醒选择。取消后不保存；原数据已替换或对象已删除时不应用旧草稿。
- 重叠预览不再只看起点后 90 天：分别检查双方开始、移动例外及最后例外之后的 370 天窗口，覆盖远期开始的计划和例外结束后的重复。预览发现冲突仍由用户决定，不自动移走任何安排；这不承诺穷举无限期的未来时区规则。
- 同一次计划的提醒在本机持久去重，划掉后旧请求不会再次发出；提醒不自动开始或停止计时。
