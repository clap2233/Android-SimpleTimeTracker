# V3.2 交付与验证

版本：`1.59-life-clock-v3.2`，版本号 164。基线 `83940dc`，Android 数据库 38→39，完整快照 schemaVersion 3，仍读取 v1／v2。使用原正式证书，可覆盖 UI2／V3／V3.1 正式包；开发包通过完整备份迁入。

## 本轮修改

- 「现在」直接显示两层活动。默认展开学习与娱乐，学习含日语、英语、剪辑、AI、阅读。原分组可单独通用计时，原活动 ID、颜色、图标、记录与排序偏好保留。
- 默认学习／PKR／创作采用退出轻提醒，锻炼与深度思考为专注子活动；普通工作、睡眠、通勤、休假旅行等自由计时。娱乐按各子项的 30／90／45／45／15 分钟轻提醒，均可修改／关闭。
- 模板覆盖活动，活动继承所属分组；每次计时固定自身规则，修改或升级不会中途改变旧计时。测试新规则时请结束旧计时，再重新开始。
- 修正周期提醒收到闹钟后受旧全局开关阻断续排的问题；闹钟广播等待本次处理完成。前台轻提示、后台通知，均不结束计时；运行卡显示提醒限制，点击系统设置，长按可复制状态。
- 快乐、意义均可空 −5～＋5，0 与空不同。两项均填才即时计算逐条合计 −10～＋10，不按周累计人生总分。保留恢复感、照片、人物与环境。
- 移除正常经历的「确认时间」及待整理操作，任何合法真实时长直接保存并计入统计。历史状态仅为旧数据兼容保留；重叠、未来、非正时长等实际错误仍明确提示。
- 奶油小猫抱森林绿时钟的新图标，包含旧版、自适应及单色资源。活动卡名称与提醒说明分配独立空间，小屏／大字号增加卡片高度。
- 手机、网页、AI、JSON 与 CSV 扩展同步；分组汇总与叶活动身份分开。新增分组只初始化一次，不在每次启动补回用户删除的子活动。
